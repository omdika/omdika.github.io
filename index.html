Oura Studio — iOS Frontend Application

Oura Studio is a custom, high-performance, native iOS inventory and production management application designed specifically for a self-production handmade accessories business (scrunchies, headbands, etc.).

The core mission is to solve the complex problem of accurate HPP (COGS) calculation when raw fabric roll material is nested and cut into multiple finished goods with different size dimensions — alongside stock ledger tracking, pricing optimization, and sales recording.

Tech Stack
  • SwiftUI
  • PostgreSQL on Supabase
  • FastAPI (Python) on Google Cloud Platform
  • Google SSO
  • Bluetooth Thermal Printer Integration
  • XLSX Generator for bulk marketplace uploads
  • QR Generator & Scanner
  • Image Server on Google Cloud Platform
