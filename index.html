Oura Studio — iOS Application

Oura Studio is a custom, high-performance, native iOS inventory and production management application designed specifically for a self-production handmade accessories business (scrunchies, headbands, and more).

The core mission is to solve the complex problem of accurate HPP (COGS) calculation when raw fabric roll material is nested and cut into multiple finished goods with different size dimensions.

Tech Stack

  • PostgreSQL DB on Supabase
  • FastAPI (Python) Backend on Google Cloud Platform
  • Google SSO
  • Bluetooth label printing

Kemah — Your Group Trip Planning Companion

Plan trips, split tasks, track expenses, and settle shared costs — without the drama.

Kemah is an iOS app that helps groups organize camping trips from preparation until every expense is settled. All trip details live in one place, so every member knows what to bring, what to do, and what to pay.

Group camping usually means endless chats, scattered packing lists, and confusing cost-sharing calculations. Kemah brings everything together into one simple flow:

  1. Create a trip and invite friends.
  2. Split tasks and gear.
  3. Log every expense.
  4. View and settle the cost split.
Key Features
  • Task Sharing — checklist for gear, tickets & logistics with assignee (PIC)
  • Flexible Budget — Per Person, Per Group, Per Assignee
  • Split Bill Engine — transparent cost-splitting calculation
  • Easy Invites — share trips via WhatsApp

News Crawler and QA Agent

This project consists of two main components: a crawler that collects news articles from Detik.com as sample test objects, and an automated QA Agent that verifies article quality.

The agent generates relevant test cases, runs verification with AI (Groq) and a search engine (Tavily), then stores the results in a PostgreSQL database.

Key Features
  • News Crawler — collects article titles, URLs, dates, and content
  • Playwright — automates data scraping from Detik.com
  • AI QA Agent — generates 3–5 test cases per article
  • Fact Checking — verification using Tavily and Groq
  • Quality Status — done, warning, flagged, or error
  • PostgreSQL — storage for articles and test results

QAgent — AI-Powered Frontend QA Automation

QAgent is a demo automation testing platform for frontend web applications. QAgent uses Playwright for browser automation, Groq AI as an agent to create and evaluate test cases, and Tavily for AI-powered web search.

This project demonstrates how the QA process can run automatically via GitHub Actions whenever a Pull Request is created or updated.

Key Features
  • Browser Automation — runs Playwright Chromium
  • Frontend Discovery — discovers pages and elements before generating tests
  • AI Test Cases — creates scenarios from user stories and Pull Request context
  • AI Evaluation — evaluates test results and determines pass/fail status
  • Bug Report — collects console errors and generates JSON reports
  • GitHub Actions — automation triggered on Pull Request
