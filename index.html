Oura Studio — iOS Application

Oura Studio is a custom, high-performance, native iOS inventory and production management application designed specifically for a self-production handmade accessories business (scrunchies, headbands, and more).

The core mission is to solve the complex problem of accurate HPP (COGS) calculation when raw fabric roll material is nested and cut into multiple finished goods with different size dimensions.

Tech Stack
  • SwiftUI
  • PostgreSQL DB on Supabase
  • FastAPI (Python) Backend on Google Cloud Platform
  • Google SSO
  • Bluetooth label printing

Kemah — Teman Merencanakan Trip Bareng

Rencanakan perjalanan, bagi tugas, catat pengeluaran, dan selesaikan urusan patungan tanpa drama.

Kemah adalah aplikasi iOS untuk membantu kelompok mengatur perjalanan camping dari persiapan sampai semua biaya selesai dibagi. Semua informasi trip tersimpan di satu tempat, sehingga setiap anggota tahu apa yang harus dibawa, dilakukan, dan dibayar.

Camping bersama biasanya berarti banyak chat, daftar barang yang tercecer, dan perhitungan patungan yang membingungkan. Kemah menyatukan semuanya dalam satu alur sederhana:

  1. Buat trip dan ajak teman.
  2. Bagi tugas dan perlengkapan.
  3. Catat setiap pengeluaran.
  4. Lihat dan selesaikan pembagian biaya.
Fitur Utama
  • Pembagian tugas — checklist barang, tiket & logistik dengan PIC
  • Budget fleksibel — Per Orang, Per Kelompok, Per PIC
  • Split Bill Engine — perhitungan patungan yang transparan
  • Undangan praktis — bagikan trip melalui WhatsApp

News Crawler and QA Agent

Proyek ini terdiri dari dua komponen utama: crawler untuk mengumpulkan artikel berita dari Detik.com sebagai sample test object, dan QA Agent otomatis untuk memverifikasi kualitas artikel.

Agent menghasilkan test case yang relevan, menjalankan verifikasi dengan AI (Groq) dan search engine (Tavily), lalu menyimpan hasil pengujian ke database PostgreSQL.

Fitur Utama
  • News Crawler — mengumpulkan judul, URL, tanggal, dan konten artikel
  • Playwright — otomatisasi pengambilan data dari Detik.com
  • AI QA Agent — menghasilkan 3–5 test case untuk tiap artikel
  • Fact Checking — verifikasi menggunakan Tavily dan Groq
  • Quality Status — done, warning, flagged, atau error
  • PostgreSQL — penyimpanan artikel dan hasil pengujian

Playwright · Groq AI · GitHub Actions

QAgent — AI-Powered Frontend QA Automation

QAgent adalah project demo automation testing platform untuk aplikasi web frontend. QAgent menggunakan Playwright untuk menjalankan browser automation, Groq AI sebagai agent yang membuat dan mengevaluasi test case, serta Tavily untuk kebutuhan web search berbasis AI.

Project ini mendemonstrasikan bagaimana proses QA dapat dijalankan otomatis melalui GitHub Actions setiap kali Pull Request dibuat atau diperbarui.

Fitur Utama
  • Browser Automation — menjalankan Playwright Chromium
  • Frontend Discovery — menemukan halaman dan elemen sebelum test dibuat
  • AI Test Cases — membuat scenario dari user story dan konteks Pull Request
  • AI Evaluation — mengevaluasi hasil test dan menentukan status pass atau fail
  • Bug Report — mengumpulkan console error dan menghasilkan laporan JSON
  • GitHub Actions — automation dengan trigger Pull Request

Telegram iOS Development AI Agent

An AI-powered Telegram coding agent connected to Google Cloud Vertex AI (Gemini) for automating iOS development with Swift and SwiftUI directly through GitHub pull requests.

The agent helps iOS developers turn natural-language instructions, screenshots, and UI references into production-ready code changes. It can inspect an existing iOS codebase, update or create Swift files, and open a pull request for review — all from Telegram.

Key Features
  • Telegram Agent — control development tasks through chat
  • Vertex AI (Gemini) — AI-powered code generation and reasoning
  • Swift & SwiftUI — create and update native iOS code
  • GitHub Pull Requests — automatically submit changes for review
